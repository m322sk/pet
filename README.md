# Tinkoff Black Cashback — кейс по продуктовой аналитике

## О проекте
Это pet-проект по продуктовой аналитике программы кэшбэка Tinkoff Black.

Цель проекта — показать полный аналитический цикл:
сырые данные в CSV -> загрузка в PostgreSQL -> очистка и нормализация -> расчёт продуктовых метрик -> проверка гипотез -> визуализация результатов в BI.

В проекте используются агрегированные данные по клиентам за апрель-сентябрь 2023 года.
На основе этих данных я анализирую активность клиентов, структуру трат по категориям, использование категорий кэшбэка и различия в поведении пользователей с расширенным набором доступных категорий.

## Какие задачи решает проект
- оценка динамики активности клиентов по месяцам
- анализ среднего оборота и кэшбэка
- изучение популярных категорий трат
- анализ выбора категорий повышенного кэшбэка
- observational-анализ связи между расширенным набором доступных категорий и долей трат в выбранных категориях

## Какой результат
В результате проекта построен воспроизводимый аналитический пайплайн:
от загрузки данных до расчёта метрик и получения бизнес-выводов.

Проект показывает навыки:
- работы с SQL и PostgreSQL
- подготовки и трансформации данных
- расчёта продуктовых метрик
- проверки гипотез
- визуализации результатов и формулирования рекомендаций для бизнеса

## Ограничения
- данные агрегированы помесячно, а не на уровне транзакций
- прямого признака подписки нет, поэтому используется proxy-признак
- результаты по группам следует интерпретировать как observational analysis, а не как causal effect
